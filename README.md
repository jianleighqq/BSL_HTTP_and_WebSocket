## 1. Project Description
This repository hosts a static website which includes my personal portfolio landing page constructed and served using the **Bonezegei Scripting Language (BSL v1.3.3)** HTTP Web Server framework. The application demonstrates low-level static HTTP server configuration, serving customized static HTML/CSS content, and managing a version-controlled project under an MIT License.

### Tech Stack
- **Server Runtime:** Bonezegei Scripting Language (BSL v1.3.3)
- **Framework / Modules:** BSL HTTP Framework (`http` module)
- **Frontend:** HTML5, CSS3
- **Version Control:** Git, GitHub

---

## 2. Setup & Execution Steps

Setting up the development environment and running the web server locally:

### Things I Installed First and Did:
1. Install **Bonezegei Scripting Language (v1.3.3)** from the Microsoft Store (Windows).
2. Install the **Bonezegei Scripting Language Formatter** extension in Visual Studio Code.
3. I verified the installation in my command prompt using:
'bonezegei -v'
4. I also installed the dependencies using:
'bzg install'


### 3. Executing the Server in the Terminal Using:
'bzg run'
The result is shown in assets/terminal-run.png
After that, I typed http://localhost:8000 in my browser and saw my project. This is seen in:
assets/browser-portfolio.png
